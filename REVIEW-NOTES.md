# OneShotLabs — complete motion review

This is a local-only review build. Nothing in this folder has been deployed to Netlify.

## What changed

- **AI:** the introduction, territory controls, constellation, supporting evidence, and AI Curve now assemble in a clear hierarchy.
- **Photography:** prints settle with restrained tonal normalization; captions arrive after the image; left/right movement is removed on phones.
- **Page continuity:** navigation remains immediate; the proposed navy wipe was removed because it provided no performance benefit.
- **Contact:** the gold rule draws first, then form fields resolve in sequence. Focus behavior is clearer and more tactile.
- **Mobile:** shorter travel, faster entrances, and tighter stagger intervals.
- **Reduced motion:** composed static states with a brief dissolve instead of spatial movement.
- **Performance:** new reveals are observer-driven and stop after completion; no new continuous animation loop was added.

## Suggested review order

1. `ai-consulting.html` — watch the hierarchy from headline to constellation to AI Curve.
2. `photography.html` — scroll through several prints and switch Home/Away.
3. `contact.html` — watch the closing rule and field sequence, then test keyboard focus.
4. Move between pages using the navigation to assess the transition.
5. Resize to a phone-width window and repeat AI, Photography, and Contact.

Close the Terminal window opened by the review launcher when finished; that stops the local preview server.

The optional online EXIF reader no longer blocks the Photography timeline. Images render immediately from local files even when the internet connection is unavailable.
